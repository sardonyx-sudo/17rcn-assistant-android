# 扶輪公益網 專屬 Android 刊登助手 (原生 APK 版)

本資料夾為專為 **Android 手機打造的獨立原生應用程式（APK）**。  
徹底擺脫行動版瀏覽器限制（解決了 17rcn.org 不相容 Firefox 行動版、第三方瀏覽器停更等痛點），提供專責人員**最穩定、零門檻、開箱即用**的極速刊登辦公工具！

---

## 🌟 核心特色與技術優勢

1. **內建原裝 Chromium 核心（100% 相容 17rcn.org）**：
   - 採用 Android 原生 `WebView`，底層即為 Google Chromium 引擎，完美相容 17rcn.org 的二級聯動選單與 KindEditor 富文本編輯器。
2. **Cookie 持久化記憶**：
   - 專責人員只需在 App 內登入 17rcn.org 帳號一次，系統自動永久記住登入狀態，下次開啟直接刊登，免反覆輸入帳密。
3. **無縫串接 Google 試算表 (GAS) 佇列**：
   - 自動撈取志工回傳的待刊物資卡片與 Google Drive 高清圖片。
   - 刊登送出後，App 自動向試算表標記「已刊登」，實現團隊流水線自動化。
4. **一鍵全自動填表 + 圖片注入**：
   - 點擊「一鍵刊登」，App 自動填滿標題、兩層分類、數量、地址、新舊與說明文，並利用 `DataTransfer` 模擬檔案拖放掛載 3 張照片。
   - 畫面自動平滑滾動並聚焦至圖形驗證碼區，人員只需肉眼掃視確認、敲入 4 碼驗證碼並按送出即可！

## ☁️ 透過 GitHub Actions 雲端一鍵編譯下載 APK（電腦完全免裝 Android Studio！）

本專案已配置完成 [`.github/workflows/build-apk.yml`](../.github/workflows/build-apk.yml)。  
您**不需要**在電腦下載幾 GB 龐大的 Android Studio，只要將專案推送到 GitHub，由微軟/GitHub 雲端伺服器為您自動編譯出相容所有 Android 手機的 `.apk` 安裝檔！

### 📥 取得 APK 步驟：

1. **將代碼推送到您的 GitHub 儲存庫**（或 Fork 本專案）：
   ```bash
   git add .
   git commit -m "feat: 新增 Android 專屬 App 與雲端編譯流程"
   git push origin main
   ```
2. **前往 GitHub 網頁觸發編譯**：
   - 打開您的 GitHub 儲存庫頁面。
   - 點擊上方選單中的 **「Actions」** 分頁。
   - 在左側工作流程清單中，點選 **「扶輪公益網助手 APK 雲端自動編譯」**。
   - 點擊右側的 **「Run workflow」** 下拉選單 ➔ 點擊綠色 **「Run workflow」** 按鈕。
3. **下載安裝檔**：
   - 約等待 **1 ~ 2 分鐘**，編譯完成後會出現綠色勾勾（✓）。
   - 點擊該筆紀錄進入詳情頁面，滑動到最下方的 **「Artifacts」** 區塊。
   - 點擊 **`扶輪公益網刊登助手-Android-APK`** 即可下載 `.zip` 壓縮檔。
   - 解壓縮後即取得 **`app-debug.apk`**！

## 📲 手機安裝與使用 SOP

1. **安裝到手機**：
   - 將 `app-debug.apk` 傳送至 Android 手機（透過 LINE、Google Drive 或 USB 傳輸）。
   - 點擊該 APK 進行安裝。若手機跳出「不安全的應用程式」或「未知來源」，請點選「**仍要安裝**」（此為 Debug 預設簽章，安全無虞）。
2. **初次設定（僅需一次）**：
   - 開啟 App，切換至 **「偏好設定」** 分頁。
   - 貼上您的 **Google Apps Script (GAS) 網址** 與 **預設地址**，點擊「儲存設定」。
   - 切換至 **「17rcn 刊登網頁」** 分頁，登入您的 17rcn 扶輪會員帳號（登入後系統將永久記住）。
3. **日常極速刊登流程**：
   - 開啟 App ➔ 在「待刊物資佇列」看到志工上傳的物資卡片。
   - 點擊卡片下方的 **「⚡ 一鍵填入並前往刊登」**。
   - App 自動載入網頁並在 1 秒內填滿所有欄位與掛載照片。
   - 輸入畫面中央的 4 碼圖形驗證碼，點擊「確認送出」。
   - App 彈出成功通知，自動回寫試算表並返回清單，**每筆作業僅需 5~10 秒！**
