# 扶輪公益網 專屬 Android 刊登助手 (原生 APK 版)

本資料夾為專為 **Android 手機打造的獨立原生應用程式（APK）**。  
徹底擺脫行動版瀏覽器限制（解決了 17rcn.org 不相容 Firefox 行動版、第三方瀏覽器停更等痛點），提供外勤拍照採集與後台審核刊登人員**最穩定、零門檻、開箱即用**的一站式極速辦公工具！

---

## 🌟 核心特色與技術架構

### 1. 📱 四大完整功能分頁
* **📸 拍照採集 (Capture)**：外勤志工可現場拍照或由相簿選取 1~3 張照片，填入所在地址與備註，點擊一鍵直接上傳至 Google 試算表並自動啟動雲端 Gemini AI 辨識。
* **📋 物資佇列 (Queue)**：即時連線雲端試算表，卡片化展示所有「待刊登」與「刊登中」物資，支援點擊一鍵刊登、雲端 AI 重新辨識、手動解鎖與刪除廢列。
* **🌐 17rcn 刊登 (Browser)**：內建 Google Chromium 原生 WebView 引擎，完美相容 17rcn.org 的二級聯動分類與 KindEditor 富文本編輯器，並提供 Cookie 永久登入記憶。
* **⚙️ 偏好設定 (Settings)**：設定 Google Apps Script (GAS) 部署網址與預設自取地址。

### 2. 🔒 多人跨端協作互鎖與安全防護 (Lease Lock)
* **狀態雙重視覺識別**：
  * 當物資被電腦端或另一部手機準備刊登時，右上角會穩定釘選 **`🔒 刊登中`** 狀態徽章。
  * 卡片外框會自動亮起加粗的 **琥珀金高亮邊框**（`#92400E`），滑動清單時一眼秒認。
* **操作防護與手動解鎖**：
  * 處於刊登中的物資，按鈕自動由「⚡ 刊登此物資」切換為「**🔓 解鎖**」。
  * 志工點擊時會主動攔截並彈窗提醒「此物資正由其他裝置刊登中」，防止多人同時發布造成重複刊登。
  * 若確認前次刊登已被中斷或無人處理，可點擊「解除鎖定」一鍵將物資恢復為「待刊登」。
* **換筆自動解鎖**：志工切換準備刊登其他物資時，系統會自動在背景向 GAS 發送解鎖上一筆，避免佔用鎖定。
* **20 分鐘逾時租約回收 (Lease Timeout)**：若裝置當機或網路斷線，試算表超過 20 分鐘後自動重設回「待刊登」，杜絕系統死鎖。
* **後端併發競態防護 (Race Condition Guard)**：點擊瞬間若被他人搶先鎖定，App 會主動捕獲失敗並中斷載入，跳出警告並自動更新佇列。

### 3. ⚡ 毫秒級自動填表與圖片注入
* 點擊「刊登此物資」，App 自動切換至刊登分頁並在 1 秒內填滿品名、兩層級分類、數量、地址、新舊與說明文。
* 透過現代瀏覽器 `DataTransfer` API 模擬檔案拖放，將雲端 Google Drive 照片無感掛載至原生網頁表單，免手動下載圖檔。
* 畫面平滑捲動並聚焦至驗證碼輸入框，志工僅需肉眼確認、輸入 4 碼驗證碼並點擊送出即可！

### 4. 🗑️ 空間防爆維護與單筆刪除
* 支援在卡片上直接「🗑️ 刪除」廢棄或重複的物資。
* 刪除時**同步將 Google Drive 中的關聯照片移至垃圾桶**並刪除試算表列，徹底防止 Google 表單 1GB 免費空間用盡。
* 嚴格安全限制：**處於「刊登中」的物資嚴禁刪除**，必須先解除鎖定才能刪除。

### 5. 🎨 日系溫暖焦糖米色系 (Warm Caramel Morandi)
* 告別生硬的刺眼色調，採用典雅、舒適耐看的焦糖褐（`#8C6239`）、燕麥金（`#F2EBD9`）與琥珀金（`#D97706`），提供長輩與志工極致親和的操作體驗。

## ☁️ 透過 GitHub Actions 雲端一鍵編譯下載 APK（電腦完全免裝 Android Studio！）

本專案已配置完整之 CI/CD 自動化工作流程 [`.github/workflows/build-apk.yml`](../.github/workflows/build-apk.yml)。  
您**完全不需要**在電腦安裝龐大的 Android Studio，只要代碼推送到 GitHub，由雲端伺服器自動為您編譯出相容所有 Android 手機的 `.apk` 安裝檔！

### 📥 取得最新 APK 步驟：

1. **將代碼推送到您的 GitHub 儲存庫**：
   ```bash
   git add .
   git commit -m "feat: 更新 Android 刊登助手"
   git push origin main
   ```
2. **前往 GitHub 網頁查看編譯**：
   - 開啟您的 GitHub 儲存庫頁面。
   - 點擊上方選單中的 **「Actions」** 分頁。
   - 點選正在執行或最新完成的 **「扶輪公益網助手 APK 雲端自動編譯」** 工作流程。
3. **下載安裝檔**：
   - 編譯約需 **1 ~ 2 分鐘**，完成後會顯示綠色勾勾（✓）。
   - 點進該筆執行紀錄，滑動至最下方的 **「Artifacts」** 區塊。
   - 點擊 **`扶輪公益網刊登助手-Android-APK`** 下載壓縮檔，解壓縮後即可取得 **`app-debug.apk`**！

## 📲 手機安裝與使用 SOP

1. **安裝到手機**：
   - 將 `app-debug.apk` 傳送至 Android 手機（透過 LINE、Google Drive 或 USB 傳輸）。
   - 點擊該 APK 進行安裝。若手機跳出「不安全的應用程式」或「未知來源」，請點選「**仍要安裝**」（此為 Debug 簽章，安全無虞）。
2. **初次設定（僅需一次）**：
   - 開啟 App，切換至 **「⚙️ 偏好設定」** 分頁。
   - 貼上您的 **Google Apps Script (GAS) 網址** 與 **預設自取地址**，點擊「儲存設定」。
   - 切換至 **「🌐 17rcn 刊登」** 分頁，登入您的 17rcn 扶輪會員帳號（登入後 Session Cookie 將永久記住）。
3. **日常極速刊登流程**：
   - 開啟 App ➔ 在「📋 物資佇列」看到物資卡片。
   - 點擊卡片下方的 **「⚡ 刊登此物資」**。
   - App 自動載入網頁並在 1 秒內填滿所有欄位與掛載照片。
   - 輸入畫面中央的 4 碼圖形驗證碼，點擊「確認送出」。
   - App 彈出成功通知，自動回寫試算表並返回佇列，**每筆刊登僅需 5~10 秒！**
